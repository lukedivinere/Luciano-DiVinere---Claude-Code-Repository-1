Step 2 · Write

The minimal correct agent

query() is the one-shot entry point — pass a prompt and options, iterate the messages it streams back.

# one-shot: fire a task, stream the result
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    options = ClaudeAgentOptions(
        system_prompt="You are an expert Python developer.",
        permission_mode="acceptEdits",   # auto-accept edits
    )
    async for message in query(prompt="Fix the bug in app.py", options=options):
        print(message)

asyncio.run(main())
// one-shot: query() returns an async-iterable Query
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Fix the bug in app.ts",
  options: { permissionMode: "acceptEdits", maxTurns: 5 },
})) {
  console.log(message);
}
Step 3 · Gate

Permission modes = how much the agent may do alone

The mode sets the default posture. For real human-in-the-loop, prefer a can_use_tool / canUseTool callback over bypassing — it approves, denies, or rewrites each call.

plan

Read-only. Proposes a plan, touches nothing.

safest

default

Standard prompting before actions run.

balanced

acceptEdits

Auto-accepts file edits; still gated elsewhere. (Python)

autonomous

bypassPermissions

No checks. Sandboxed, fully-trusted runs only.

The #1 gotcha

Custom tools are named by assembly

A custom tool's allow-list identifier is built from the server key and the tool name. Mismatch these and the tool silently never runs.
