# Brothers Landscape & Design — new website (Modern look)

The dark, bold version of the Brothers Landscape site (City Heights, San Diego), built on the
Modern template. A lighter **Classic** version is in `../brothers-landscape/`. Open `index.html`
in any browser — no build step.

Same real business info, placeholders, and to-confirm items as the Classic version — see
`../brothers-landscape/README.md`. Both share the one-block `SITE` config for rebranding, and both
have a clickable "Our Work" gallery at the bottom (each photo opens full-size) that currently uses
placeholder stock photos to swap for Brothers' own high-resolution job photos.
