# Demo Website Templates

A collection of polished, reusable single-page website templates for pitching local
small-business owners. Each template is self-contained (one HTML file + an `images/`
folder), rebrandable in a few edits, and needs no build step — just open it in a browser.

## How to use one

1. Open the template's folder and read its `README.md` — it lists every swap point.
2. Edit the `SITE` config block, `<title>`/meta, brand colors, and drop in the client's photos.
3. Open `index.html` in a browser to preview, or host it (any static host works).

Each template shares the same conventions so once you've customized one, the rest feel familiar:
a single `index.html`, a `SITE` config block for business details, brand colors as CSS variables
at the top, an `images/` folder, and a per-template `README.md` customization guide.
